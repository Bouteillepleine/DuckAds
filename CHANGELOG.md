# Changelog

## v1.0.12

First public release.

- hosts engine parsing hosts, AdBlock, dnsmasq, RPZ and plain domain lists
- 46 source catalog plus custom URLs
- nine injection modes probed at boot, SUSFS autobind, NoMount support
- DoH / DoT bypass blocking through iptables, entered only on new connections
- per-app exemptions via NoMount, KernelSU app profiles or the Magisk denylist
- scheduled updates, Wi-Fi only
- WebUI: status, lists, rules, apps, settings
